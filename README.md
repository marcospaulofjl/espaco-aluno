# 🎓 Espaço Aluno - Painel do Estudante

> Projeto de verificação e consolidação de informações acadêmicas, desenvolvido para simplificar a visualização de pendências, prazos e notas dos estudantes.

---

## 📌 Sobre o Projeto
O **Espaço Aluno** é uma solução voltada para estudantes universitários acompanharem de forma ágil suas atividades, trabalhos acadêmicos e prazos de entrega em um único painel intuitivo.

---

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Versionamento & Hospedagem:** Git, GitHub, GitHub Pages
* **Documentação & Integrações:** Markdown, LinkedIn
